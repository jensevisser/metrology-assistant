# vLLM Docs Assistant

Een lokaal draaiende RAG-engine (en later agent) die vragen beantwoordt over de officiële [vLLM](https://github.com/vllm-project/vllm)-documentatie, met bronvermelding naar de gebruikte passages.
Gebouwd stap voor stap met een evaluatieset als meetlat: elke wijziging aan de pipeline wordt vóór en na gemeten, en de documentatie is vastgezet op één release, zodat scores vergelijkbaar blijven.

**Status:** in opbouw (Project 1, Sprint 0: een LLM aanroepen en meten).

Licentie: MIT. De vLLM-documentatie (Apache 2.0) staat niet in deze repo; een downloadscript haalt haar op met bronvermelding.
