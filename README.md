# Metrology Assistant

Een lokaal draaiende RAG-engine (en later agent) die vragen beantwoordt over meetonzekerheid en calibratie, met bronvermelding naar openbare documenten zoals JCGM 100 (GUM) en EA-4/02.
Gebouwd stap voor stap met een evaluatieset als meetlat: elke wijziging aan de pipeline wordt vóór en na gemeten.

**Status:** in opbouw (Project 1, Sprint 0).

Licentie: MIT. Documenten van derden staan niet in deze repo; ze worden via een downloadscript met bronvermelding opgehaald.
